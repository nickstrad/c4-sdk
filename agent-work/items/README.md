# Work items

Each coordinated item gets a directory named with a stable ID, containing `brief.md`, `claims.md`, `review.md`, and a maintained `STATE.md` checkpoint (or a link to the effort’s existing checkpoint). Copy the templates from [`templates/`](templates/) and fill them in before implementation. Keep one item per directory so parallel work can claim disjoint paths and reviewers can find the evidence together.

Read and maintain the checkpoint according to [the restart-state protocol](../../AGENTS.md#restart-state), including before compaction or handoff. Name its path and owner in the brief. Keep separately owned planning checkpoints untouched.
