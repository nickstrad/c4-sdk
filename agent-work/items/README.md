# Work items

Each coordinated item gets a directory named with a stable ID, containing `brief.md`, `claims.md`, and `review.md`. Copy the templates from [`templates/`](templates/) and fill them in before implementation. Keep one item per directory so parallel work can claim disjoint paths and reviewers can find the evidence together.
